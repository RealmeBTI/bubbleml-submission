# Public Security Audit

## Scope and method

The filtered public-release staging tree was generated by
`scripts/prepare_public_release.py` in a fresh temporary directory. Its own
`RELEASE_SHA256SUMS.txt` was verified from that directory. Text artifacts were
scanned for `/Users/` and `/home/` absolute paths and for high-confidence
private-key, AWS-secret, API-key assignment, and bearer-token patterns.

## Result

| Check | Result |
|---|---|
| Release manifest hashes | PASS (all staged files verified) |
| `/Users/` or `/home/` path hits | 0 |
| High-confidence secret hits | 0 |
| Credentials exposed or removed | None found; none printed |

The staging transform redacts incidental local paths in eligible text artifacts
only; it does not alter scientific values, hashes, or labels.

`NO_SECRETS = PASS`\
`NO_UNAUTHORIZED_PRIVATE_PATHS = PASS`
