# CMAME graphical abstract

`cmame_graphical_abstract.tex` is a manually authored TikZ vector schematic.
It uses only the audited protocol and reported result scope: the 11-seed CUDA
tutorial comparison, its confirmed mass-conservation finding, the descriptive
five-seed cross-condition check, and the tutorial-only intervention result.

The compiled `cmame_graphical_abstract.pdf` has a 13.833 x 5.531 inch canvas,
corresponding to 1328 x 531 pixels at 96 dpi. It therefore meets CMAME's stated
minimum graphical-abstract dimensions while remaining editable from the TeX
source. No generative-AI artwork was used.
