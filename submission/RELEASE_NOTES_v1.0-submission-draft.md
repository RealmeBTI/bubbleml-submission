# v1.0-submission-draft

First submission-package snapshot for the BubbleML physics-aware benchmark.

Included:

- BubbleML preprocessing, model, training, evaluation, statistical, and plotting code.
- Available per-seed configs and training histories.
- Audited tutorial, bounded-alpha, divergence, rollout, and compact cross-condition results.
- Reviewer-facing stored-result self-test.
- Submission figures, manuscript source, attachment sources, and supplementary package.

Not included:

- Raw BubbleML data.
- Full checkpoint archive.
- Complete cloud-side per-seed cross-condition export.
- Human author/funding/COI metadata, public URLs, DOI, or a repository code license.

This is a local draft tag, not a public release. See `ARTIFACT_GAPS.md` and
`REMAINING_HUMAN_ACTIONS.md` before publishing.
