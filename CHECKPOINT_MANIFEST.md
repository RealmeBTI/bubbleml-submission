# Checkpoint Manifest

No model checkpoint binaries are committed in this release. The repository does
contain configuration files, retained metrics, and training histories where they
were available. Four representative external checkpoint hashes are listed in
`CHECKSUMS.md`; those hash records do not make the binaries available.

The complete checkpoint set and the cross-condition per-seed checkpoint
provenance were unavailable during the local release audit. Consequently, this
repository supports code and stored-result analysis reproduction, not a full
checkpoint-based training or field-snapshot reproduction. See `ARTIFACT_GAPS.md`
for the complete boundary.
